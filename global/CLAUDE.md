## Project workflow
- A project with `ROADMAP.md` and `HANDOFF.md` uses the document-driven workflow: read its `CLAUDE.md` first and follow its task rules; use `/next-task` for roadmap work and `/phase-end` at phase ends and gates.
- Starting a new project, or substantial work in one without those files: offer `/workflow-setup` once. If declined, don't raise it again in that project.
